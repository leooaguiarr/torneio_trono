# Execute e implante seu app AI Studio

Aqui você encontra tudo o que precisa para rodar seu aplicativo localmente.
https://ai.studio/apps/9445b0f5-1e0e-44df-bf6a-218f91a4cff0

## Rodar Localmente

**Pré-requisitos:** Node.js


1. Instale as dependências:
   `npm install`
2. Defina a `GEMINI_API_KEY` no arquivo [.env.local](.env.local) com a sua chave da API do Gemini
3. Inicie o aplicativo:
   `npm run dev`
